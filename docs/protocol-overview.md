# Protocol Overview

Stupidinu is not an operational mainnet launch. It is a conservative protocol design scaffold for a memecoin environment where $STUPIDINU tracks market conditions, reward accounting, and mission-aware experimentation while $USELESS functions as the reward asset.

## Trust assumptions

- Read-only market monitoring is considered low risk.
- Reward computation depends on snapshot integrity and explicit rules.
- Any live onchain execution requires an explicit deployment and signer configuration.
- The reward mechanism is documented as a holder-reward model, not a guarantee.
